# BossLand v3.13 - v1.21.5 / 26.3

## Обзор

BossLand — это всеобъемлющий плагин для Minecraft, который расширяет vanilla-геймплей, добавляя **21 уникального custom-босса** разных уровней. Изначально создан **Eliminator** и остановлен после Minecraft 1.19, этот проект продолжает разработку, чтобы привнести улучшенный опыт сражений с боссами в современные версии Minecraft.

## Авторы

**Оригинальный автор:** Eliminator  
**Оригинальный репозиторий:** https://bitbucket.org/Eliminator/bossland/  
**Оригинальный ресурс SpigotMC:** https://www.spigotmc.org/resources/boss-land.68320/

Это продолжение направлено на сохранение оригинального видения при обновлении совместимости и добавлении новых функций для текущих версий Minecraft.

## Особенности

### Основная концепция

Убили Дракона Края? Путь только начался! Плагин добавляет прогрессивную систему боссов с **четырьмя различными уровнями** сложных встреч, каждое с уникальными наградами и механиками.

### Система прогрессии боссов

#### **Боссы уровня 1** (6 боссов)

Входные боссы, призываемые в определенных биомах с помощью обычных материалов:

- **Папа Панда** (Бамбуковый биом) — выбивает коричневый осколок
- **Король Слизней** (Болото) — выбивает зеленый осколок
- **Кролик-Убийца** (Пустыня) — выбивает серый осколок
- **Король Зомби** (Равнины) — выбивает красный осколок
- **Герцог Гастов** (Нижний мир) — выбивает белый осколок
- **Король Скелетов-Иссохших** (Нижний мир) — выбивает черный осколок

#### **Боссы уровня 2** (4 босса)

Боссы среднего уровня, требующие созданных предметов-осколков из побед над боссами уровня 1:

- **Гигант** (Равнины) — выбивает изумрудный осколок
- **Король Иллов** (Саванна) — выбивает золотой осколок
- **Злой Колдун** (Снежный биом) — выбивает синий осколок
- **Демон** (Особые условия) — выбивает демонический осколок

#### **Боссы-Боги уровня 3** (3 босса)

Боссы высокого уровня с уникальными требованиями призыва:

- **Эфирный Бог** — призывается при Y=200 с помощью Запретного Плода
- **Бог-Фараон** — призывается в пустыне с помощью Запретного Плода
- **Утонувший Бог** — призывается в океане при Y=-40 с помощью Запретного Плода

#### **Бессмертные боссы уровня 4** (2 босса)

Итоговые сражения энд-гейма:

- **Дьявол** — призывается в Нижнем мире с помощью Отвратительного Плода
- **Смерть** — призывается с помощью предмета Смертная Тетрадь

#### **Боссы, добавленные в этом форке** (6 боссов)

Призываются памятниками из `recipes.yml` → `shrine_recipes`:

- **Гнев** — выбивает скрижаль Гнева
- **Ледяной Титан** — снежные биомы
- **Океанский Левиафан** — океан
- **Владыка Нижнего Мира** — Незер
- **Колосс Края** — Край
- **Лесной Страж** — лесные биомы

### Система прогрессии боссов (Тиры)

Все боссы разделены на **4 уровня сложности**. Каждый босс нижнего уровня дропает предмет, из которого крафтится предмет призыва босса следующего уровня:

| Тир | Боссы | Как призывать | Что дропают |
|-----|-------|---------------|-------------|
| **Tier 1** | King Slime, Killer Bunny, Zombie King, Ghast Lord, Wither Skeleton King, Papa Panda | Ритуал в мире (блоки + активатор) | Базовые осколки (Зелёный, Серый, Красный, Белый, Чёрный, Коричневый) |
| **Tier 2** | Giant, Illager King, Evil Wizard, Demon, Forest Guardian | Предмет, крафченый из осколков Tier 1 + ритуал | Улучшенные предметы (Изумрудный, Золотой, Синий, Демонический осколки, Эссенция Природы) |
| **Tier 3** | Aether God, Pharaoh God, Drowned God, Ocean Leviathan, Frost Titan | Предмет, крафченый из предметов Tier 2 + ритуал | Редкие предметы (Запретный Плод, Ядро Льда, Чешуя Бездны, Инфернальное Ядро, Осколок Кристалла Края) |
| **Tier 4** | Devil, Death, Nether Overlord, End Colossus | Предмет, крафченый из предметов Tier 3 + ритуал | Финальный лут (Смертная Тетрадь, Отвратительный Плод и др.) |

**Крафт предметов призыва через осколки:**

| Предмет призыва | Крафтится из | Для призыва босса |
|-----------------|--------------|-------------------|
| **Эссенция Природы** | Зелёный + Коричневый + Красный осколки | Forest Guardian (Tier 2) |
| **Ядро Льда** | Синий + Изумрудный осколки | Frost Titan (Tier 3) |
| **Чешуя Бездны** | Чёрный + Красный осколки | Ocean Leviathan (Tier 3) |
| **Инфернальное Ядро** | Ядро Льда + Чешуя Бездны | Nether Overlord (Tier 4) |
| **Осколок Кристалла Края** | Инфернальное Ядро + Ядро Льда | End Colossus (Tier 4) |
| **Запретный Плод** | Изумрудный + Золотой + Синий осколки | Aether God, Pharaoh God, Drowned God (Tier 3) |
| **Отвратительный Плод** | Демонический осколок + Запретный Плод | Devil (Tier 4) |
| **Смертная Тетрадь** | Звезда Края + Книга Знаний | Death (Tier 4) |

**Пример полной цепочки progresstion:**
1. Убейте **King Slime** → получите **Зелёный осколок**
2. Крафтите **Эссенцию Природы** из осколков Tier 1
3. Призовите **Forest Guardian** (Tier 2) через ритуал с Эссенцией
4. Убейте **Evil Wizard** (Tier 2) → получите **Ядро Льда** (или крафтите из осколков Tier 2)
5. Крафтите **Ядро Льда** из Синего + Изумрудного осколков Tier 2
6. Призовите **Frost Titan** (Tier 3) через ритуал с Ядром Льда
7. Убейте **Aether God** (Tier 3) → получите **Инфернальное Ядро**
8. Крафтите **Инфернальное Ядро** из Ядра Льда + Чешуи Бездны
9. Призовите **Nether Overlord** (Tier 4) через ритуал в Низере с Инфернальным Ядром

Все предметы призыва имеют curse-чару (нельзя выбросить) и могут быть получены только дропом с босса предыдущего уровня или крафтом из осколков предыдущих тиров.

#### **Мини-боссы при копании**

При добыче блоков игрок рискует разбудить мини-босса. Каждые N добытых блоков делается одна попытка спавна с шансом X% — рядом с игроком появляется мини-босс, а в чат и на экран приходит сообщение «Вы потревожили глубинное зло!».

**Частота по умолчанию (v3.0):** порог 200 блоков, шанс 35% → в среднем один мини-босс примерно на 570 блоков (раньше — на 20 000).

**Уровни мини-боссов:**
- **Обычные** — Зомби, Скелет, Паук, Пещерный паук, Крипер, Топпи, Хаск, Стрей. Здоровье 100 ед. (настраивается), шанс дропа 3%.
- **Элитные** (12% при спавне) — Ведьма, Эвокер, Равагер, Эндермен, Шалкер, Виндикатор, Пиллиджер. Здоровье 300 ед., шанс дропа 15%, до 3 осколков сразу, дополнительные эффекты сопротивления и поглощения.

Мини-боссы имеют полоску здоровья (BossBar), кастомное имя, повышенное здоровье (умножается на `bossHealthMultiplier`), уникальные способности по типу и редкий лут — осколки боссов для призыва обычных боссов. Криперы взрываются при смерти (можно отключить).

**Зона сражения.** Пока игрок в радиусе `despawnRadius` от мини-босса, он видит полосу здоровья. Если игрок выходит из радиуса (умер и возродился далеко, телепортировался, вышел из игры), в чат приходит предупреждение «Вы покидаете зону сражения! Вернитесь в течение N сек., иначе мини-босс исчезнет». Если за `despawnDelaySeconds` никто не вернулся, мини-босс исчезает без награды (с дымом и звуком), запись о нём удаляется из `save.yml`. Вернулся вовремя — приходит «Вы вернулись в зону сражения», отсчёт сбрасывается.

**Настройка в `config.yml` → `miniboss`:**

```yaml
miniboss:
  enabled: true              # главный выключатель
  disabledWorlds: [MyTownWorld]
  blockThreshold: 200        # сколько блоков добыть до попытки спавна
  spawnChance: 35            # шанс успеха попытки, %
  eliteChance: 12            # шанс, что мини-босс будет элитным, %
  cooldownSeconds: 120       # пауза после спавна для игрока, сек (0 = выкл)
  maxNearby: 2               # сколько мини-боссов может быть живо рядом
  nearbyRadius: 64           # радиус проверки maxNearby
  minY: -60                  # границы по высоте
  maxY: 320
  announceRadius: 80         # кому показывать уведомление
  playSpawnSound: true
  baseHealth: 100            # здоровье обычного / элитного
  eliteHealth: 300
  barColor: RED              # полоска обычных / элитных
  barStyle: SOLID
  eliteBarColor: PURPLE
  dropChance: 3              # шанс дропа осколка, %
  eliteDropChance: 15
  eliteDropAmountMax: 3      # максимум осколков с элитного
  creeperExplodesOnDeath: true
  despawnWhenAlone: true     # убирать мини-босса, если рядом никого нет
  despawnRadius: 48          # радиус зоны сражения, блоки
  despawnDelaySeconds: 120   # сколько секунд без игроков — и мини-босс исчезает
  types:                     # какие типы появляются и как часто
    ZOMBIE:
      enabled: true
      weight: 10
    WITCH:
      enabled: false         # пример: ведьм отключили
      weight: 10
```

**Посох контроля** (дроп с Эфирного Бога) переключает режим через Shift + использование:

- **осколок** — с боссов падают только осколки;
- **лут** — осколки не выпадают, только снаряжение;
- **контроль** — посох захватывает сущность.

Подписи режимов настраиваются в `lang.yml` → `items.staffModeShard / staffModeLoot / staffModeControl`,
шаблон строки в лоре — `items.staffModeLore` (`<mode>` подставляется автоматически).

Ручной спавн для проверки: `/bl-admin miniboss [тип]` (работает и из консоли).
Убрать оставшихся мини-боссов: `/bl-admin killMiniBosses [мир]`.

**Составные предметы** (Ядро Льда, Чешуя Бездны, Инфернальное Ядро, Осколок Кристалла Края)
собираются из двух ингредиентов в среднем ряду верстака — например, Ядро Льда = синий осколок + изумрудный.
Раньше каждый из них требовал кольцо из 8 предметов, и цепочка Тира 4 стоила сотни осколков.

- Боссы уровня 1 и 2 выбивают магические осколки
- Осколки используются для создания предметов призыва более высокоуровневых боссов
- Физическая система создания — расставляйте предметы в мире, а не на верстаке
- При удержании осколка игрок получает зельевые эффекты — хорошие и плохие

#### **Привязка к биомам**

- Каждый босс требует определенные условия биома
- Уникальные ритуалы призыва с расположением блоков в мире
- Нет традиционных рецептов création — все через взаимодействие с миром

#### **Прогрессивная сложность**

- Каждый уровень предлагает значительно большую сложность
- Лучшее снаряжение и магические предметы получаются через прогрессию
- Некоторые боссы доступны только после победы над другими

## Руководство (`/bl guide`)

Книга-руководство открывается командой `/bl guide` (или `/bossland guide`) и из книги «Полное руководство по BossLand».

Разделы: боссы, предметы, осколки, рецепты, броня, авторы и информация о плагине. В каждом меню есть кнопка
**«Поиск»**: нажмите её, напишите в чат название босса или предмета (например, «герцог» или «ядро») —
откроется список совпадений, клик по которому ведёт сразу на страницу рецепта. Чтобы передумать, напишите
`отмена`; через 60 секунд ожидание снимается само. Если чат перекрыт другим плагином, тот же поиск вызывается
командой `/bl search <название>`, например `/bl search герцог`.

## Команды

### Основная команда: `/bossland` или `/bl`

#### Доступные подкоманды:

- `/bl guide` — выдает книгу-руководство
- `/bl search <название>` — открывает руководство сразу на результатах поиска
- `/bl help` — показывает список доступных команд
- `/bl info` — показывает информацию о плагине

### Админ-команда: `/bosslandadmin` или `/bl-admin`

**Права:** `bl-admin.cmds`

#### Доступные подкоманды:

- `/bl-admin help` — показывает список доступных команд
- `/bl-admin spawn <босс>` — призывает конкретного босса
- `/bl-admin cspawn <босс> [x y z] [мир]` — призывает босса по координатам в мире
- `/bl-admin loot <босс>` — выдает случайный лут босса
- `/bl-admin sloot <босс> <ид лута>` — выдает конкретный лут по ID
- `/bl-admin setLoot <босс> <ид>` — установить лут для босса
- `/bl-admin addLoot <босс>` — добавить лут для босса
- `/bl-admin killBosses <мир>` — удалить всех боссов в мире
- `/bl-admin killMiniBosses [мир]` — убить мини-боссов обычной смертью (с наградой и без висящих полосок здоровья)
- `/bl-admin reload` — перезагрузить конфигурацию плагина
- `/bl-admin selftest` — самопроверка установки: сверяет названия осколков из дропа боссов с `lang.yml`
  и проверяет, что каждый предмет призыва собирается из осколков в сетке крафта. Полезна после правки
  `config.yml`/`recipes.yml` — сразу показывает, какое имя или рецепт разошлись

## Установка

1. Скачайте JAR-файл плагина
2. Поместите его в папку `plugins` вашего сервера
3. Перезапустите сервер
4. Конфигурационные файлы сгенерируются автоматически

## Зависимости

- **Требуется:** Spigot/Paper/Purpur 1.21.5 – 26.3, Java 21+ (для Minecraft 26.x сервер требует Java 25)
- **Опционально:** WorldGuard (защита регионов)

## Совместимость

Сборка проверяется автоматически на реальных серверах:

| Сервер | Версия | Java | Статус |
|--------|--------|------|--------|
| Paper | 1.21.5 | 21 | ✅ плагин включается, все 21 босс спавнятся |
| Purpur | 26.3 (build 2654) | 25 | ✅ плагин включается, все 21 босс спавнятся |

Версии Minecraft 26.x используют новую нумерацию (26.3 = третий релиз 2026 года) и требуют Java 25 на стороне сервера; сам плагин собран под Java 21, поэтому работает и на старых, и на новых сборках.

## Сборка

Требуется JDK 21 и Maven 3.9+:

```bash
mvn clean package
```

Готовый плагин появится в `target/` (`bossland-<версия>.jar`, shaded — bStats уже внутри).
Зависимости плагина (`spigot-api`, WorldGuard/WorldEdit) подтягиваются из публичных Maven-репозиториев, перечисленных в `pom.xml`.

### Автоматическая сборка (GitHub Actions)

В репозитории настроен workflow [`.github/workflows/build.yml`](.github/workflows/build.yml):

- собирает плагин на каждый push в любую ветку и на pull request в `main`;
- проверяет содержимое jar (главный класс, конфиги, bStats);
- прогоняет smoke-тест: поднимает настоящий Paper 1.21.5 и проверяет, что плагин включается без ошибок (на тегах, PR и при ручном запуске);
- на push тега `v*` (или при ручном запуске с указанием тега) прикрепляет собранный jar к GitHub-релизу.

### Продолжение разработки

- **Цель:** Сохранить оригинальный геймплей, добавив улучшения качества жизни
- **v2.4:** Обновление для MC v1.21.5 (API Spigot 1.21.5, Java 21)
- **v2.5–v2.6:** Мини-боссы при копании, элитные мини-боссы с уникальными способностями
- **v2.8:** Progresstion-цепочка призывающих предметов (осколки T1 → T2 → T3 → T4)
- **v2.9:** Фиксы компиляции против Spigot API 1.21.5, совместимость с Minecraft 26.x (проверено на Purpur 26.3), исправление частиц (устаревшие имена и обязательные данные), CI со smoke-тестами на Paper 1.21.5 и Purpur 26.3
- **v3.13:** Разделы «Предметы» и «Брони» больше не вписаны в код. Списки были перечислением пар «босс — номер лута», из-за чего в руководстве не было ни Морозного Клинка, ни Зова Прилива, ни Тесака Инферно, ни Клинка Пустоты, ни Зелёного Стража, ни мечей Гнева — то есть всего оружия боссов 3.8. Теперь весь лут боссов разбирается по разделам: осколки — по имени, броня — по типу предмета, всё остальное именованное — в «Предметы». Список вырос с 14 до 29 вещей. Самопроверка следит, что каждый именованный предмет дропа показан хотя бы в одном разделе книги, — так дыра не появится снова
- **v3.12:** Ванильная книга рецептов перестала врать. Рецепты регистрировались в сервере обычными материалами («2 красителя + блок»), поэтому ванильная книга показывала их доступными, как только у игрока находились красители, — а крафт молча пустел. Теперь сервер знает рецепт как точный предмет (ExactChoice): книга показывает настоящий осколок и подсвечивает рецепт, только когда он действительно есть в инвентаре. Чтобы осколок с мини-босса (у него другой лор) тоже годился в крафт, плагин подбирает результат сам по recipes.yml — узор ищется в любом месте сетки, как в обычном верстаке. Собрали узор обычными материалами — результат пуст, но игрок получает объяснение. Самопроверка прогоняет каждый рецепт через подбор дважды: настоящими осколками (должен собраться) и обычными материалами (не должен, но должен объясняться)
- **v3.11:** Разделы книги связаны. Клик по осколку в разделе «Осколки» раньше не делал ничего: узнать, с какого босса он падает, можно было только через поиск. Теперь у осколка своя страница — боссы, которые его роняют (клик ведёт на страницу босса), и предметы, которые из него крафтятся (клик ведёт на рецепт). Осколок в строке дропа на странице босса тоже кликабелен. Список осколков больше не вписан в код: он ищется по всему дропу боссов, поэтому осколок нового босса попадает в руководство сам, а Осколок Края (он крафтится, а не падает) наконец видно в разделе «Осколки». Заодно починен клик в разделе «Боссы»: страница открывалась по типу материала иконки, из-за чего Ледяной Титан, Левиафан, Повелитель Нижнего мира, Колосс Края и Хранитель Леса не открывались вовсе (5 боссов из 21)
- **v3.10:** Подсказки в игре. Игрок, получив первый осколок, теперь видит сообщение «Тебе выпал осколок босса. Напиши /bl guide — там рецепты призыва» — один раз, отметка хранится на игроке. Если рецепт собран целиком, но обычными материалами вместо осколков, верстак больше не молча пустеет: игрок получает объяснение «Для предметов призыва нужны осколки с именем, а не обычные материалы» (не чаще раза в 15 секунд). У осколков с мини-боссов в лоре появилась строка «Рецепты призыва — в руководстве: /bl guide». Обе подсказки отключаются в config.yml (`hints.firstShard`, `hints.craftBlocked`), тексты — в lang.yml. Самопроверка `/bl-admin selftest` проверяет, что обычные материалы не проходят крафт и что объяснение при этом действительно показывается для каждого рецепта
- **v3.9:** Рецепты стало видно. Раздел «Рецепты» в руководстве показывал только 6 рецептов из 23 — остальные (в том числе все предметы призыва 3.8, Ядро Льда, Чешуя Бездны) были вписаны в код и туда не попадали; теперь список строится из `recipes.yml`, а страница открывается по ключу, записанному в сам предмет, а не по типу материала. Страница босса больше не рисует схему постройки, которая с 3.8 ни на что не влияет: вместо неё показывается сетка крафта предмета призыва, а клик по предмету призыва открывает его рецепт. В разделе «Осколки» у каждого осколка дописан список предметов, в крафт которых он идёт — список собирается из `recipes.yml`, поэтому не устареет. Лор самих осколков сокращён до подсказки «Нужен для крафта предметов призыва» + «Что именно — в руководстве: /bl guide»: полный перечень больше не врёт после правки рецептов. Заголовок страницы рецепта — название предмета, а не ключ из конфига. Самопроверка `/bl-admin selftest` проверяет, что каждый осколок идёт хотя бы в один рецепт и что у каждого рецепта есть результат с названием
- **v3.8:** Призыв без построек. Раньше любой ритуал требовал собрать из блоков святилище (кольцо или крест 3×3) — теперь достаточно скрафтить предмет призыва из осколков и нажать правую кнопку: босс появляется там, где игрок кликает (или прямо на месте игрока, если клик в воздух). Место тоже больше не важно: призывать можно где угодно, старые правила (биом, измерение, высота) включаются настройкой `rituals.requireBiome`, а постройка святилища — `rituals.requireShrine` (обе выключены по умолчанию). У всех 16 ритуальных боссов теперь свой крафтовый предмет: для восьми из них (Король Слизней, Папа-Панда, Кролик-Убийца, Король Зомби, Король Иссечённых, Герцог Гастов, Гнев, Демон) предметы призыва добавлены впервые — Слизистое Ядро, Талисман Панды, Лапка Кролика, Печать Нежити, Печать Иссечённых, Печать Гастов, Печать Гнева, Печать Демона (каждая — 2 осколка нужного цвета и тематический материал). Три бога больше не делят один Запретный Плод: из него теперь крафтятся Плод Эфира, Плод Фараона и Плод Бездны, а Дьявол приходит по Отвратительному Плоду в любом мире. Сам Запретный Плод стал основой для крафта, а не призывом. Самопроверка `/bl-admin selftest` следит, что предмет призыва у каждого босса свой, что его можно скрафтить и что он совпадает с тем, что показано в руководстве
- **v3.7:** Ритуалы призыва починены. Условия восьми боссов (Злой Колдун, Король Иллов, Гигант, Лесной Страж, Ледяной Титан, Океанский Левиафан, Владыка Нижнего Мира, Колосс Края) сравнить было нельзя: код искал в руке англ. `Book of Spells`/`Bell of Doom`/`Potion of Giant Growth` и русские имена с литералом `&l` вместо `§l`, а ошибка молча глоталась пустым `catch`. Теперь все 16 ритуалов описаны в одной таблице, имя предмета призыва берётся из `lang.yml`, а структура святилища — из `recipes.yml`, то есть из той же записи, которую игрок видит в руководстве (у Ледяного Титана и Океанского Левиафана книга и код расходились: кольцо и центр были переставлены). Если предмет и место подходят, а структура нет — игрок получит подсказку, а не тишину; ошибки ритуалов пишутся в консоль. Меню «Боссы» строится из `recipes.yml`, поэтому в руководство добавлен Гнев (кольцо из медных блоков с железным блоком в центре, тыква-фонарь, Y ниже −40). Самопроверка `/bl-admin selftest` сверяет каждый ритуал: босс есть в config.yml, материал и имя активатора совпадают с тем, что выдаёт плагин, структура совпадает с книгой, и у каждой страницы руководства есть работающий ритуал
- **v3.6:** Поиск по руководству. Кнопка «Поиск» раньше отвечала «функция в разработке» — теперь она открывает поиск по названиям боссов и предметов: игрок пишет запрос в чат, получает список совпадений и сразу переходит на нужную страницу рецепта. Работают современное событие чата Paper и классическое Spigot, есть отмена словом `отмена` и таймаут 60 секунд. Самопроверка `/bl-admin selftest` проверяет, что поиск находит боссов и предметы и не выдаёт ничего на бессмысленный запрос
- **v3.5:** Составные рецепты подешевели: Ядро Льда, Чешуя Бездны, Инфернальное Ядро и Осколок Кристалла Края собираются из двух ингредиентов в среднем ряду вместо кольца из 8. Меню «Информация о плагине» показывает реальную версию из `plugin.yml` и актуальный диапазон 1.21.5 – 26.3. README: 21 босс вместо 15, добавлено описание шести боссов этого форка. Убран отладочный вывод в консоль (`Make Boss` на каждый удар, `Block Cancel Land`, ошибки зачарований) — теперь через логгер на уровне FINE
- **v3.4:** Починены режимы посоха контроля: осколок определялся по английскому ключу `Shard`, которого нет в русских названиях, а сам лор посоха содержал «Режим: осколок» — из-за этого режимы «осколки» и «лут» не фильтровали дроп вовсе. Теперь осколки сверяются по списку имён из `lang.yml`, подписи режимов и сообщение о смене режима — на русском (настраиваются в `lang.yml`), самопроверка проверяет режимы посоха
- **v3.3:** Зона сражения у мини-боссов. Полосу здоровья видит любой игрок в радиусе `despawnRadius`, а не только тот, кто заспавнил босса. При выходе из зоны приходит предупреждение «Вы покидаете зону сражения» с обратным отсчётом, при возвращении — «Вы вернулись в зону сражения». Если рядом никого нет дольше `despawnDelaySeconds`, мини-босс исчезает без награды и стирается из `save.yml`; мини-босс, оставшийся в выгруженном чанке, удаляется, а не возвращается «призраком»
- **v3.2:** Починены мини-боссы: смерть больше не роняет обработчик (`NullPointerException`), награда выдаётся, полоса здоровья убирается после боя, а удар по мини-боссу больше не считается ударом по боссу. Добавлена команда `/bl-admin killMiniBosses`. Секция `miniboss` в `lang.yml` вынесена на верхний уровень — раньше имена мини-боссов не находились и отображались как `Missing!`. Осколки в рецептах ищутся по именам из `lang.yml`, поэтому в книге-руководстве снова видны реальные ингредиенты, а проверка крафта покрывает все 12 рецептов. `lang.yml` при обновлении дополняется недостающими ключами из jar, значения `Missing!` чинятся автоматически и больше в файл не пишутся
- **v3.1:** Русская локализация консоли и комментариев `config.yml`, исправлены ссылки на загрузку в README, добавлена самопроверка `/bl-admin selftest` (34 проверки) в CI. Починен крафт предметов призыва: проверка ингредиентов строится из `recipes.yml` и больше не сдвинута относительно сетки, обычные материалы вместо осколков больше не проходят
- **v3.0:** Полный русский перевод конфига (21 босс, 70 предметов, 173 строки лора, названия и лор памятников боссов), имена осколков синхронизированы с `lang.yml` (починен крафт), отдельная графа `miniboss` с 22 настройками, мини-боссы появляются ~в 35 раз чаще, команда `/bl-admin miniboss`
